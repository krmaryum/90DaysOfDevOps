Docker Build & Push in GitHub Actions – 25 Questions

Quiz Overview

This quiz is based on Day 45: building a complete Docker CI/CD pipeline using GitHub Actions and Docker Hub.

Total Questions: 25
Topics: Dockerfile, GitHub Actions, Docker Hub, Tags, Badge, CI/CD
Passing Target: 20/25 or higher
Practice Style: Select one answer for each question
1. What was the main goal of Day 45?
Correct answer: B. Day 45 focused on building a complete CI/CD pipeline that builds a Docker image and pushes it to Docker Hub.
2. Which file contains the instructions to build a Docker image?
Correct answer: A. A Dockerfile contains the build instructions for a Docker image.
3. In this project, which base image was used in the Dockerfile?
Correct answer: C. The Dockerfile used nginx:alpine to serve a simple HTML page.
4. What does this Dockerfile line do: COPY index.html /usr/share/nginx/html/index.html?
Correct answer: D. Nginx serves files from /usr/share/nginx/html/.
5. What does EXPOSE 80 mean in a Dockerfile?
Correct answer: B. EXPOSE documents the container port, but -p is still needed to publish it.
6. Which command builds a Docker image locally?
Correct answer: A. docker build -t image-name . builds an image from the Dockerfile in the current directory.
7. What does -p 8080:80 mean in docker run?
Correct answer: C. The left side is the host/local port, and the right side is the container port.
8. What is the workflow file path used for Docker CI/CD?
Correct answer: B. GitHub Actions workflows are stored inside .github/workflows/.
9. What does actions/checkout@v4 do?
Correct answer: D. Without checkout, the runner will not have your Dockerfile and app files.
10. Why do we use GitHub Secrets for Docker Hub login?
Correct answer: A. Secrets keep sensitive values out of the workflow YAML.
11. Which two secrets were used for Docker Hub authentication?
Correct answer: B. The workflow uses DOCKER_USERNAME and DOCKER_TOKEN.
12. What is the purpose of the latest Docker tag?
Correct answer: C. latest is commonly used to point to the newest pushed image.
13. Why is a sha-<short-commit-hash> Docker tag useful?
Correct answer: A. SHA tags help with traceability, debugging, and rollback.
14. Which command gets the first 7 characters of the commit SHA in the workflow?
Correct answer: D. $GITHUB_SHA contains the full commit SHA, and cut -c1-7 keeps the first 7 characters.
15. What does $GITHUB_OUTPUT help us do?
Correct answer: B. It lets a step save an output such as SHORT_SHA.
16. In Task 4, what was the purpose of if: github.ref == 'refs/heads/main'?
Correct answer: C. The condition makes publishing happen only from the main branch.
17. What should happen when the workflow runs on a feature branch?
Correct answer: A. Feature branches should validate the build but not publish images.
18. What does the pattern "**" mean under push branches?
Correct answer: D. "**" allows the workflow to run on pushes to all branches.
19. Why is the pattern “Build everywhere, push only from main” useful?
Correct answer: B. This is safer because only main branch code gets published to Docker Hub.
20. What does a GitHub Actions status badge show?
Correct answer: C. A status badge shows the current workflow status.
21. Where is the status badge usually added?
Correct answer: A. Status badges are commonly placed near the top of README.md.
22. Which command pulls the image from Docker Hub?
Correct answer: D. docker pull downloads an image from Docker Hub or another registry.
23. Which command confirms that the container is running?
Correct answer: B. docker ps lists running containers.
24. What does docker rm -f dockerhub-test do?
Correct answer: C. It stops and removes the container if it exists.
25. What is the correct full journey from code to running container?
Correct answer: A. This is the full CI/CD flow from source code to a running container.
