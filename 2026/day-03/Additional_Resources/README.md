## How to Open

Download a quiz and open the HTML file in a modern browser with JavaScript enabled. Normal GitHub file links show source rather than a running quiz. The files contain their own styles, question data, and scripts; no external asset references were found during source inspection.

## Preservation and Review

All three quiz files are unchanged. Source inspection found 57 questions in total; browser behavior and answer accuracy were not comprehensively tested. The networking quiz puts every correct choice first and shuffles questions rather than options. Keep this limitation in mind for revision; optional improvements can be considered separately.
