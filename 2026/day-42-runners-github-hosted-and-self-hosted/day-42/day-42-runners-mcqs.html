1 What is a GitHub Actions runner?
Explanation: A runner is the machine/server where GitHub Actions job commands are executed.
2 Which keyword selects the runner for a job?
Explanation: `runs-on` tells GitHub Actions which runner should execute the job.
3 Which runner label is used for Ubuntu GitHub-hosted runners?
Explanation: `ubuntu-latest` is used to run a job on a GitHub-hosted Ubuntu runner.
4 Who manages GitHub-hosted runners?
Explanation: GitHub manages the OS, updates, tools, infrastructure, and cleanup for GitHub-hosted runners.
5 Which trigger allows a workflow to run manually from the GitHub Actions UI?
Explanation: `workflow_dispatch` allows manual workflow execution from the GitHub Actions UI.
6 What does `on: push` do in a workflow?
Explanation: `on: push` triggers the workflow whenever code is pushed to the repository.
7 In Task 1, why could Ubuntu, Windows, and macOS jobs run in parallel?
Explanation: Independent jobs without dependencies can run in parallel.
8 Which command prints the current user on Linux/macOS runners?
Explanation: `whoami` prints the current user running the job.
9 Which command checks the Git version?
Explanation: `git --version` prints the installed Git version.
10 Why do pre-installed tools matter on GitHub-hosted runners?
Explanation: Pre-installed tools help workflows start faster and avoid repeated installation steps.
11 Which tool is commonly used for containers and image builds?
Explanation: Docker is used for containers and container image builds.
12 Where do you add a new self-hosted runner from in a repository?
Explanation: The repository runner setup is found under Settings → Actions → Runners.
13 What command starts a self-hosted runner in the foreground?
Explanation: `./run.sh` starts the configured self-hosted runner and waits for jobs.
14 What does the GitHub runner status `Idle` mean?
Explanation: `Idle` means the runner is online and ready to receive jobs.
15 Which command can install a self-hosted runner as a service?
Explanation: `sudo ./svc.sh install` installs the runner service.
16 What does `runs-on: self-hosted` mean?
Explanation: `runs-on: self-hosted` targets an available runner with the `self-hosted` label.
17 Which command shows the machine name where the job is running?
Explanation: `hostname` prints the machine hostname, useful for confirming the job ran on your VM.
18 Which command prints the current working directory?
Explanation: `pwd` prints the current working directory.
19 Where is a file usually created during a self-hosted runner workflow?
Explanation: Workflow files are usually created inside the runner workspace under `_work/repo-name/repo-name`.
20 Which command can search for the created test file under the runner directory?
Explanation: `find` can search the runner directory for the test file.
21 What is a runner label?
Explanation: Labels are tags that help GitHub Actions select matching self-hosted runners.
22 What does `runs-on: [self-hosted, my-linux-runner]` require?
Explanation: The runner must match all labels in the array.
23 Why are labels useful when you have multiple self-hosted runners?
Explanation: Labels help route jobs to the correct runner when you have multiple runners.
24 Which statement best describes self-hosted runner security?
Explanation: With self-hosted runners, you control the machine and are responsible for updates, access, and security.
25 Which comparison is correct?
Explanation: GitHub-hosted runners are managed by GitHub, while self-hosted runners are managed by you or your organization.
