# Important Commands

```bash
echo "Hello" > file.txt
echo "Hello" >> file.txt
cat < file.txt
command 2> error.log
command > output.log
command > /dev/null 2>&1
echo "Error" >&2
```

---

# Quick Memory Tricks

```text
0 = stdin
1 = stdout
2 = stderr
```

```text
>    = Overwrite
>>   = Append
<    = Input
2>   = Error Output
2>&1 = Send stderr to stdout
/dev/null = Black Hole
```
