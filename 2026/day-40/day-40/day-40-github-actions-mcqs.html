1. What is the main purpose of GitHub Actions?
GitHub Actions is used to automate workflows such as testing, building, deployment, and other CI/CD tasks.
2. Where must GitHub Actions workflow files be stored?
GitHub detects workflow YAML files only when they are placed inside the .github/workflows/ directory.
3. Which file did you create for the first workflow in Day 40?
The first workflow file was hello.yml inside .github/workflows/.
4. In a workflow file, what does `on: push` mean?
`on: push` tells GitHub Actions to run the workflow whenever code is pushed to the repository.
5. What does the `jobs:` key define in GitHub Actions?
`jobs:` contains one or more jobs that GitHub Actions will run.
6. In your workflow, what was the job name?
The Day 40 workflow used one job called `greet`.
7. What does `runs-on: ubuntu-latest` mean?
`runs-on: ubuntu-latest` tells GitHub to run the job on a fresh Ubuntu Linux runner in the cloud.
8. What are `steps:` in a GitHub Actions job?
`steps:` are the individual commands or actions that run one by one inside a job.
9. What does `uses: actions/checkout@v4` do?
`actions/checkout@v4` checks out the repository code so the runner can access the files.
10. What does the `run:` key do?
`run:` executes shell commands such as echo, date, ls, or test commands on the runner.
11. What does `name:` on a step provide?
Step-level `name:` gives the step a clear label in the GitHub Actions logs.
12. Which command prints a hello message in the workflow?
In Linux shell, `echo` prints text to the output.
13. Which command prints the current date and time on the runner?
The `date` command prints the current date and time.
14. Which GitHub Actions variable prints the branch name that triggered the run?
`${{ github.ref_name }}` returns the branch or tag name that triggered the workflow.
15. Which variable prints the full commit ID that triggered the workflow?
`${{ github.sha }}` gives the commit SHA for the commit that triggered the workflow run.
16. Which Bash expression prints the first 7 characters of the commit SHA?
`${GITHUB_SHA::7}` is Bash substring syntax that prints the first 7 characters of the GITHUB_SHA environment variable.
17. Which command lists files in the repository on the runner?
`ls -la` lists files and folders, including hidden files, in the current directory.
18. Which variable prints the runner operating system?
`${{ runner.os }}` prints the runner operating system, such as Linux, Windows, or macOS.
19. What does a green check mark mean in GitHub Actions?
A green check mark means the workflow/job completed successfully.
20. What does a red X usually mean in GitHub Actions?
A red X means the workflow, job, or step failed.
21. Which command can intentionally fail a workflow step?
`exit 1` returns a non-zero exit code, so the step fails.
22. What does exit code `0` usually mean?
Exit code 0 normally means the command completed successfully.
23. What does exit code `1` usually mean?
A non-zero exit code, such as 1, usually means failure.
24. Where do you read workflow errors in GitHub Actions?
To troubleshoot, open the failed workflow run, click the failed job, expand the failed step, and read the logs.
25. Why is breaking a workflow on purpose useful for learning?
Intentionally breaking a workflow helps you learn how to recognize failed pipelines, open logs, find errors, and fix issues.
